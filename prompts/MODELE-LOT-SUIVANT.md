# Modèle d'instruction pour les lots suivants

Les instructions des lots 1 à 6 seront rédigées une par une, après validation du lot précédent, sur ce modèle :

1. **Lecture obligatoire** : `CLAUDE.md`, la section du lot dans `docs/LOTS.md`, `docs/PRODUIT.md`,
   `docs/DESIGN.md` et les maquettes concernées, `docs/DECISIONS.md`.
2. **Reformulation avant de coder** : 10 lignes au plus, puis attente du « Go ».
3. **Périmètre exact** : copié de `docs/LOTS.md`, avec les tables, écrans et autorisations du lot.
4. **Hors périmètre** : la liste explicite de ce qui ne doit pas être touché.
5. **Critères de fin** : vérifiables, chacun prouvé par un test ou une démonstration.
6. **Livraison** : branche `lot-N-<nom>`, Pull Request, rapport selon `RAPPORT-DE-LOT.md`, aucune fusion.
