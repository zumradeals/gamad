# PLUS TARD — registre des idées

Ces idées sont conservées pour ne pas être perdues. **Elles ne font pas autorité** et ne doivent pas être
construites tant qu'une décision ne les fait pas entrer dans un lot.

| Idée | Comment elle s'ajoutera au socle |
| --- | --- |
| Organisations (entreprises, associations, coopératives) | Nouveau type de Monde |
| Startup issue d'un projet, toujours rattachée à sa ZUMRA | Nouveau type de Monde, relié au projet et à la ZUMRA d'origine |
| Outils spécialisés (stockage de documents type Drive, gestion, vente, etc.) | Onglet « Outils » branché sur un Monde |
| Contributions mensuelles et leurs avantages | Lot dédié (voir `LOTS.md`, lot 6) |
| Investissement dans un projet | Après avis juridique (D-020) |
| Événements (rencontres, Ziara, journées d'échanges) | Élément d'un Monde + type de publication |
| Chat en direct | Remplace le fil de discussion simple de ZUMRA |
| Inscription par téléphone (SMS / WhatsApp) | Ajout au module d'authentification |
| Fédération d'identité avec GAMAD Core | Derrière l'interface d'authentification isolée |
| Missions, Transmissions, Preuves formelles, ZAHAB, Satellites | Concepts de l'ancien dépôt, à réexaminer un par un |
| Recommandations personnalisées | Après que le réseau a assez de données réelles |
| Langues autres que le français | Fichiers de traduction Laravel |
| Commenter une publication | À décider par le Président (masqué au Lot 2, D-090) |
| Partager une publication | À décider par le Président (masqué au Lot 2, D-090) |
